Goal: Write a program to be uploaded to a RaspberryPi and connected to an LED matrix.

The text will display "Good morning/afternoon/night" depending on time of day, and if today is a holiday it will instead display "Happy [holiday name]!". It is also connected to a list of birthdays and if today is someone's birthday, it will display 'It's [name]'s B-day!"

This project is a birthday gift to my dad, so all birthdays are people he knows and some additional holidays have been added in (e.g. National Engineer's Day)


I am using pygame to simulate what the LED matrices will show before connecting them (example below)
